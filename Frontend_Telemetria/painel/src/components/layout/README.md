# `components/layout/` — moldura do painel

Elementos que ficam sempre na tela enquanto o usuário navega pelas abas.

| Arquivo | O que faz |
|---|---|
| `Sidebar.tsx` | Menu lateral: lista das abas, atalhos para **Backend** e **Cronômetro** (abrem em nova guia) e botão para recolher. No celular vira uma gaveta |
| `Header.tsx` | Barra superior: botão do menu, indicador de telemetria ativa, indicador de gravação em andamento, quem está online, botão do Modo Piloto, modo escuro/claro e sair |
| `PrintStyles.tsx` | Estilos de impressão: ao imprimir, esconde tudo e deixa visível só a área `#area-graficos` da aba Análise |
